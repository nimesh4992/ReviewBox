Architecture Specification

Zero-Hallucination Grounding

Standard AI drafting fails because models make up API parameters, support links, or release timelines. ReviewBox implements a deterministic waterfall pipeline.

When a synced review arrives, the engine indexes the review. When drafting replies, the console pulls exact references from your synced Notion Knowledge Base and release notes, ensuring factual, verified responses.

// ReviewBox Grounded Reply Flow Pipeline async function generateGroundedReply(reviewId) { const review = await db.reviews.findUnique(reviewId); // 1. Search semantic vectors in Knowledge Base const relevantDocs = await kb.searchEmbeddings(review.text, { limit: 3 }); // 2. Query target version release notes const releaseNotes = await releases.findVersion(review.appVersion); // 3. Generate grounded completion via cached context template return AI.completions.create({ model: "llama-3.3-70b-versatile", groundingDocs: relevantDocs, changelog: releaseNotes, tone: "technical_helpful" }); }
